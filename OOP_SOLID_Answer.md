
Explain how creating and using classes supports Object Oriented Programming and S.O.L.I.D. design principles, give specific examples ?

Creating and using classes directly supports Object-Oriented Programming because class helps represent real-world things and situation. In addition, we can also create objects based on these classes. Indeed, when someone writes a class it defines the general behavior a whole category of objects can have. Because of classes several real-world situations can be modeled with object-oriented programming. For example, the textbook uses a Dog class to represent a dog in general. Using attributes such as a dog’s name and age, with behaviors like sit () and roll-over (). In fact, after creating the class, we can create different dog objects from it. This shows how classes can be used to support Object-Oriented Programming by modeling real-world things and their behaviors.

 In addition, classes support the SOLID principle because they help organize and give each class a specific responsibility.  For instance, the Single Responsibility Principle means one class should have a main job. According to the textbook example a Battery class can handle battery information, on the other hand, an Electric Car class can handle information about the car. Indeed, this makes the code much easier and concise and easy to understand. The other main important SOLID principle that classes support is Open/Closed principle. In these principal classes must be easy to extend without changing existing code. More specifically Open/Closed principle means that classes should be open for extension but closed for modification. For example, from the previous example we could create an ElectricCar class based on a car class and add battery features without changing the original Car class.
